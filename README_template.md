[soundtrack] NAZWA_UTWORU

## Stems + MIDI + Presets for Audio & Production

**Quick Start**: Extract ZIP and see folders below.

### 📦 What's Inside

#### `/stems`
6-stem source separation via Demucs (`htdemucs_6s`):
- **Vocals** – Lead melodies, pads, atmospheric elements
- **Drums** – Kick, snare, percussion patterns
- **Bass** – Low-end fundamental frequencies
- **Piano** – Harmonic foundation, chord progressions
- **Guitar** – Chord progressions and textures
- **Other** – Additional textures, effects, synths

Format: 44.1 kHz, 16-bit WAV files.

#### `/midi` (6 MIDI files)
Melodic extraction via Basic Pitch:
- One MIDI per stem category
- Ready for re-synthesis with any VST/synth
- Edit velocities, timing, humanization as needed

#### `../presets` (Root Asset-Pack Presets)
GeneralUser GS v1.472.sf2 - GM-compatible soundfont with 200+ instruments
- Located in the root directory of this asset pack
- Load into DAW (FL Studio, Logic, Reaper, Ableton)
- Includes drum mapping (Bank 120) and program mapping CSVs

#### `/spectrograms`
Visual reference of frequency content per stem (PNG format).

#### `/audio_basic_meta.csv`
Track metadata (File path, Duration in seconds, Sample rate, Bit depth).
